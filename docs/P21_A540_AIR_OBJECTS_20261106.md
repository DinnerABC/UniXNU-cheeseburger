## Owned public-selector object chain

`NativeMetal540Objects.{h,mm}` implements a finite owned Library/Function/PSO/
Buffer/Queue/CommandBuffer/ComputeEncoder chain. `newLibraryWithData:` accepts
only the exact original653424B metallib SHA, and onlypadding_gradient exists.
Input/code/reflection/constants are snapshotted and hash-checked against the
compiled registry. Unknown libraries, entries, variants, parameters and
unsupported options fail rather than being substituted by probes.

`NativeMetal540OwnedRun` runs after all regressions succeed and their connection
closes. A new exclusive ABI connection initializes the owned objects. The
ObjC context is retained by the session so an asynchronous worker cannot use a
stack context after a deadline. The worker publishes CPU input/code bytes,
executes one IB, waits on a real fence, then reads buffer.contents. Connection
retirement retains all mapping owners; it is not permission to free failed DMA.

Implemented selection is exactly3 buffers3120/1024/48B and4×64 groups. It is not
an arbitraryAIR/JIT interface. CPU mappings follow the already verified
inhibit-cache NativeAdreno contract; Shared enum is not a claim of full Metal
cache behavior. The object classes deliberately do not claim complete MTL*
protocol conformance, _MTLDevice inheritance or system factory registration.
