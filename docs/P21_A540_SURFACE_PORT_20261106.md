## 实际 semantic engine

`NativeMetal540Surface::Transport` 同步 callbacks 包含 call/mapView、Create、getters、Lock/Unlock、cache、retainContext/releaseContext、releaseSurface、record。硬性前提为 exclusive connection、已核对 NEWBO CPU inhibit-cache、mapped holds cover all、有效 context 与独立 retain callback。引擎只允许一次 run，任何失败不 GPU retry/free/unmap/reset，析构不释放 context/surface。

严格 getter 准入：非零 surfaceID，RGBA FourCC 0x52474241，64×64，pitch256，element4、1×1 element，planeCount0，plane0 地址/尺寸/pitch/element 与全局 getters 完全一致，base 非零并 4096 对齐，allocation **恰好16384** 且 CPU pointer range 无溢出。拒绝 align-down、prefix、padding、其它格式和实际 allocation rounding。Create 请求值不能代替 getter 证据；write lock 与成功 fence 后 read lock 内再次核对身份/base/getters。

流程：

1. 持有 context；核对 ABI、HostImport、36-bit、A540 mounted aperture。
2. Create 私有 fresh、unpublished surface，getter 准入。
3. write Lock 内只写 sentinel `0x13579bdf`，检查 Unlock rc。
4. IB8192、VS4096、FS4096、scratch4096 为四 NEWBO；target16384 为一个 BoImport。
5. GPU IOVA 不重叠，沿原 renderer `va_start+0x100000` 布局；target 无 token、BoCpuMap 或 mapView。所有 task views 归 retained context 所有。
6. **原样复用** `Native540Render::encode` 与 `render_fixture.h` fixed VS/FS；IB/shader/scratch 初始化与原 renderer 相同，target 不再次写入。背景是 GPU 2D clear，三角形是真 VS/FS 编码。
7. 对四 NEWBO 做 inhibit-cache ordering；对 target **实际完整准确 VA/16384 cached range** 做公开 `sys_dcache_flush`。验证 IB/ISA upload；仅 IB 放入一次 submit，wait200ms。依赖 kernel job 保留全部 mapped BO，不把 target/shader作为 IB 提交。
8. 仅真正成功 wait 后 read Lock、getters 检查、target exact range cache acquire、scratch ordering，再读 scratch ts1/2/3 和原 `Native540Render::verify` oracle。当前 wrapper 的 acquire 仅 ordering，物理 invalidate 在内核 WaitFence 成功返回前完成（首轮为 userland flush，未证明成功）。内部968/外部2744/edge384；edge 不比较。检查 read Unlock 后才设 readbackVerified。

submit/wait/timeout 失败：不 read Lock、不 post-cache、不补读 scratch/pixels、不 teardown。cache/getters/lock 等错误保留原 rc、阶段、锁状态和所有 owners。oracle/timestamp 首错不会被随后 Unlock rc 覆盖，四 lock/unlock rc 独立记录。

## 实际 ObjC wrapper 与 integration

ARC `Native540SurfaceSession` 用 IOServiceOpen(service,task,0x4147) 开 **独立连接**，IOObjectRetain(service)。`IOSurfaceCreate` 只使用公开尺寸/pitch/element/format/alloc properties，不 Lookup、不发布 MachPort 或全局 pool。Getters、Lock/Unlock、`sys_dcache_flush` 均公开 SDK API。不得将 NEWBO 的 DSB 用作 cached surface flush 证明。

```objc
Native540SurfaceSession *session = [[Native540SurfaceSession alloc]
    initWithService:service record:sink context:opaque owner:strongOwner error:&rc];
if (session) {
    rc = [session runWithPrerequisites:YES];
    NativeMetal540Surface::Record evidence = [session result];
    int retirement = [session retireWithConfirmation:nil];
    // success pixel rc and RetirementPending are separate outcomes.
}
```

sink 类型 `void (*)(void *,const NativeMetal540Surface::Record &)`。非空 opaque context 必须有明确 strong owner；记录只 complete/first failure 一次，在 close 前转发。`Record.connection` 是真实当前 **0x4147 ABI connection**，sink 可同步发 metadata，但不得关闭该连接；不使用 type1 observer 写 ABI metadata。wrapper 不直接写 metadata，默认 stderr 只 SF540、SP、SI 与独立 SE，主 agent sink 对应持久日志。Record 包含 surfaceID/base/allocation/pitch、IOVA、cachephase/range、fence、lock 四 rc/seed、ts、pixels/counts 和 owner/retirement 状态。

**当前 ABI 无可靠 complete 成功确认。** 默认 `retireWithConfirmation:nil` 最多 close 一次，然后返回 RetirementPending(-5464)，`retirementConfirmed=false`，self/surface/task views/context/service 强保留到进程/本轮 boot 结束。IOServiceClose 成功不是 desc complete/DMA retirement 证明。像素成功可以独立 PASS；不得强行传 YES。只有主 agent 独立确认全部 imported desc complete 成功且 DMA 已停止后才调用可信 confirmation；否则不释放、不重新 complete/free/unmap。最多本 probe 一个 surface16384B，保守持有明确可接受。

Stage/CachePhase 定义见 header，不修改 wire ABI。Complete=24、Fence=18、Verify=22；NoCache0、PublishBO1、PublishSurface2、AcquireBO3、AcquireSurface4。状态含 future explicit confirmed gate，不宣称当前 kernel 能提供该确认。
