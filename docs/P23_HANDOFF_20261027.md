## 5. 接续开发顺序（建议）

### Step 1：先决定目标

- **只要快速有画面**：走第 2 节 P21 iPadOS17 恢复，不要做 Stage C。
- **要 iPhone X iOS16**：继续 Stage C，先不要动设备。
- **要 8 核 iPadOS17**：P22 R7，单独验证。

### Step 2：完成 20H392 主机输入

1. 确认 SystemOS APFS UUID；
2. 用 `seed-data-skip-setup-20H360.py` 的副本，把 `BUILD` 改为 `20H392`，对 `owner-data-1g.dbr` 生成 skip-setup seed；
3. 做 root 所有权 pass（参考 P23 `out/p23/ios-16.7.11/data-seed/skip-setup-1g-d242-owned.json` 的 217 路径/uid/gid 方法）；
4. 生成 20H392 root policies/manifests；
5. 生成 iPhone X ADT：
   - root-matching = DADD93F8-DBBF-4B17-A1DF-0F11E64172F7
   - product/model/target/idiom/button 用 D22AP 值
   - 1125×2436 逻辑画布
   - 保留 CPU/UFS/PSCI/display 硬件节点
6. 记录 userdata 写入计划与回滚备份，不执行。

### Step 3：修 xnu8796 补丁

按 cumulative 顺序：

1. 先修 4 个 conflict；
2. 再修 6 个 partial；
3. 重点：`source-machine-layer`、`sleh.c` boot progress、`offline-owner-systemos-mount`、`native-aes-personality`；
4. 每修一个补丁就保存项目内 patch，不要只改临时树；
5. 不要在 8796 上继续叠加 10063 的 MIG/display workaround。

### Step 4：板级驱动重编译

针对 8796/iOS16 头文件重新编译：

- ArmDTPlatform
- ArmCpu
- NativeUfs
- SoftwareAES
- AppleKeyStoreState
- RamBlock
- NativeLegacyDisplay
- touch/keys/HID
- 现有 8 核/PSCI/显示适配

当前 `scripts/p23-build-board-runtime.py` 是 10063 版，需要新 recipe；不要覆盖 P23 旧 archive。

### Step 5：prelink / payload

使用 20H392 kernelcache 和 4.7 的常量：

- `kernelcache_sha256 = 2ec297ba…`
- `esi = com.apple.driver.AppleMobileFileIntegrity=0xfffffff004e23cc0`
- `slide/roots` 按 20H392 重新生成
- trust bundle 用 4.4
- Data seed 用 Step 2
- ADT 用 Step 2
- 当前 UEFI 2 GiB/window-range 可复用，但要确认 8796 接受 2 GiB 窗口

### Step 6：一次实机验证

- 写 20H392 root 到 userdata 前单独授权；
- 严格一次 `fastboot boot`；
- 读日志：
  - root/SystemOS UUID = DADD/正确 SystemOS
  - launchd
  - display selector 4/5
  - frames
  - jetsam
- 失败只改一个变量，不循环。

## 8. 风险与未决问题

1. **20H392 SystemOS UUID 未确认**；root policies 需要它。
2. **Data seed 还没有 skip-setup/root ownership**，不能部署。
3. **xnu8796 4 个 conflict/6 个 partial 未修**；尤其 `source-machine-layer`、`sleh.c`、`owner-systemos-mount`。
4. **20H392 kernelcache 是 8796.142.1.703.8**，源 tag 用 8796.141.3；需要确认 source/donor 差异是否影响 4K/API。
5. **iPhone X identity 与当前 iPad7,1 ADT 需要重做**；显示画布 1125×2436。
6. **20H392 root 与当前 P23 root/Data/trust 不兼容**；不能混用。
7. **P23 工作区有未提交的 board.toml/BoardRuntime 修改**；接续前先决定是否恢复 1 GiB 基线，避免把 fajita 画布/2 GiB 误带进 Stage C。
8. **设备当前是否仍在 Recovery 未复核**；任何启动前先确认序列号和 bootmode。
9. 7.8 GB root 镜像未做全盘 SHA256；只做了 SHNGROOT header/window 校验，部署前建议在 host 上补全或至少校验窗口。
10. 不要在 8796 上继续叠加 10063 的 MIG/display 兼容补丁。
