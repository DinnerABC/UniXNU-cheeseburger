|---|---:|---:|---|

## 真正raster PM4

单IB顺序：

1. existingBlit540 restore/begin2D，GPU R32_UINT solidclear黑色背景 `0xff000000`，clear timestamp scratch+0=1。
2. 再完整sysmemrestore，SP/RB/TPL1 64bitaddress，CCU color/depth invalidation，CS关闭。
3. shader/cacheobject配置；VS与FS绑定各自NEWBO；VS block8加载；gl_Position→VPC link；HLSQallocationupdate后FS block12加载。
4. constants沿上游composition：无memory prefix，真实VS3immediate载入20起，driver0..3来自exact nonindexed start0/baseinstance0的40word零driverparams；FS无constants。不是猜driver资源。
5. 全viewport、scissors、MRT0RGBA8/linear/pitch256/arraypitch16384，其他7MRT清零，depth/stencil/LRZ/flags/plane清零，无blend/textures/MSAA。
6. **CP_DRAW_INDX_OFFSET op0x38，DI_PT_TRILIST=4，nonindexedsource2，instances1/count3**。不是compute填色，不是CP_MEM_WRITE。
7. CCUcolorflush timestamp scratch+8=2；UCHEflush scratch+16=3，各自WAIT_REG_MEM；barrier；只IB作为PM4submitbuffer，existingservice持有所有mappedBO。
8. oneSubmit/oneWait200ms，成功后CPU order/readback；检查timestamp1/2/3以及像素。

CPU target初始化只写sentinel `0x13579bdf`。**不向target上传expectedtriangle或background**；background来自GPU2Dclear。redexpected只存在readback comparator。center(32,32)应 `0xff0000ff`，corner(0,0)应`0xff000000`。还用整数half-pixel edge tests比较内部/外部像素，排除约1pixeledgeband，明确不声称边界fillrule全覆盖。RGBA byte顺序为内存`ff 00 00 ff`中心 / `00 00 00 ff`背景。
